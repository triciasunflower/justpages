# Invitation Card Studio v8

This version is a **full minimal redesign** focused on cleaner invitation templates and an optional sticker system.

## What's new
- Rebuilt the invitation templates with **minimal design styles**
  - thin borders
  - double borders
  - arch frames
  - editorial rules
  - side stripes
  - center plaques
  - top bands
  - corner line details
- Each invitation category now has **category-specific clean designs**.
  - Save the Date / Wedding no longer shows birthday-style graphics.
  - Birthday and Kids Birthday have their own simple celebratory styles.
  - Baby Shower, Bridal Shower, Graduation, Holiday, and General each have their own design set.
- Added a **sticker panel**:
  - click a sticker to add it
  - drag it on the card preview
  - resize the selected sticker
  - rotate the selected sticker
  - delete one sticker or clear all
- No asset-based theme images are required.

## Files
- `index.html`
- `style.css`
- `app.js`

## Notes
- The preview is also the printable output.
- Stickers are rendered inside the card and will print with the card.
- If your browser seems to show an older version, hard refresh after upload.
